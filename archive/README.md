本目录保存“闻荫开发标准流程”形成过程中的历史文档和试点实现，用于设计追溯、经验复盘和后续版本改进。这里的内容已经停止维护，不代表当前有效规范。

## 使用边界

1. 安装 Skill 时，只能使用仓库根目录的 [`skills/winin-dev-sop/`](../skills/winin-dev-sop/)。
2. 执行开发任务时，以根目录 [README](../README.md)、[开发人员一页操作卡](../开发人员一页操作卡.md)和当前 Skill 为准。
3. 归档中的脚本、提示词、目录名和流程状态可能已经失效，不应复制到业务项目中直接运行。
4. 如需从历史资料恢复某项能力，应先按当前轻量化目标重新评估，再迁移到当前版本。

归档保留的是演进依据，不是第二套并行规范。
