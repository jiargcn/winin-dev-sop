# 项目准备卡

## 目的

项目准备卡是项目事实来源，避免每个开发人员和 AI 重复寻找目录、命令、DDL、接口和负责人。机器可读文件固定为 `.ai-sop/project-profile.json`。

## 建立方式

1. 运行 `scripts/New-AiSopProjectProfileDraft.ps1`，从 Git、构建文件、`pom.xml`、`package.json`、README、DDL 和契约文件生成草稿。
2. AI 再读取 GitHub Actions、AGENTS.md 和业务资料，校正能够从仓库证明的内容。
3. 无法从仓库确认的负责人、数据边界、权威资料来源和环境要求才询问项目成员。
4. 每项命令必须在干净环境中实际执行一次，再把 `verified` 改为 `true`。
5. 版本、路径、命令和负责人变化时更新准备卡。

`sopVersion` 由公司发布包维护，项目准备卡、任务状态和 CI 必须保持一致。升级 Skill 后使用项目初始化脚本更新验证器和 Schema，并检查差异。

## 最低要求

开始普通局部任务前，至少确认项目名称、代码目录、测试或构建命令、AI 禁止访问内容。涉及数据库、接口、安全和生产任务时，还必须有对应资料来源和负责人。

准备卡缺失时，Skill 应自动生成草稿，而不是要求开发人员从空白模板逐项填写。无法确认的字段保留空值并写入任务缺失资料。
