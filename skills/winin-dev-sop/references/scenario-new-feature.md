# 新增功能

## 适用条件

在现有系统中增加原来不存在的业务能力。若只是改变已有规则或页面，使用“修改现有功能”；若只改展示，使用“简单修改”。

```mermaid
flowchart LR
    A["确认业务结果"] --> B["定位扩展点和现有模式"]
    B --> C["设计最小端到端切片"]
    C --> D["设计正常与异常测试"]
    D --> E["人工确认方案"]
    E --> F["分步实现和验证"]
    F --> G["回归、复核和总结"]
```

## 执行动作

1. 找到最接近的现有功能作为架构和代码风格参考，并说明哪些部分可复用、哪些业务规则不同。
2. 定义从界面或接口到服务、数据和权限的最小端到端切片。
3. 明确新能力与现有流程的边界，不顺带建设尚未验收的扩展能力。
4. 测试至少覆盖主流程、必填与边界、权限、失败处理以及受影响的原功能。
5. 方案和测试设计经开发人员确认后再编码。

## 示例

任务：工单列表新增按产线和计划日期组合筛选。

AI 应先确认日期口径和组合规则，定位现有筛选实现、接口契约和索引，再给出最小修改方案及单项、组合、空值、边界和原筛选回归测试。不能只增加两个页面控件便宣称完成。
