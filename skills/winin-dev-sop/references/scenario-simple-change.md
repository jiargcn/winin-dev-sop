# 简单修改

## 适用条件

只修改文案、静态样式、展示顺序、非业务配置等，并且不改变接口、数据结构、权限、计算结果、流程和业务状态。任何一项不满足都升级为“修改现有功能”。

```mermaid
flowchart LR
    A["确认仅影响展示"] --> B["定位最小文件"]
    B --> C["实施修改"]
    C --> D["运行最近测试或构建"]
    D --> E["检查页面和最终差异"]
    E --> F["人工确认结果"]
```

## 执行动作

1. 证明变更不影响数据绑定、接口参数、权限和业务逻辑。
2. 只修改最小文件，不建立完整知识图谱，不编写大篇方案。将 `plan.approvalRequired` 设为 `false`，跳过方案确认。
3. 执行与改动相关的测试、构建或最小可重复检查（使用项目里已有的测试/构建命令，不要假设特定框架）。
4. 检查实际页面、渲染结果或产物，不能只检查源码文本。
5. 最终仍由开发人员确认展示结果：先展示目标、文件级差异、验证结果和剩余风险，再等待回复 `确认结果`。

## 示例

任务：把“生产订单号”标题改为“工单号”，不改变字段和查询条件。

AI 应确认只是显示文本，修改对应资源或组件，运行相关测试或构建并检查页面。若字段名、接口参数或导出标题也要变化，应升级场景。

一份已填好的任务形状（示例数据，不是活任务）见 `assets/examples/simple-change-label-rename/`。
